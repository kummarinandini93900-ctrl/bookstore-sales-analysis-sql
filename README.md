# Bookstore Sales Analysis - SQL Project

## Project Overview
This project analyzes bookstore sales data using MySQL.

## Tools Used
- MySQL Workbench
- SQL

## Dataset
- 50 Book Sales Records

## SQL Concepts Used
- COUNT()
- SUM()
- AVG()
- GROUP BY
- ORDER BY
- LIMIT

## Key Findings
- Harry Potter generated the highest revenue.
- Revenue analyzed by city and category.
- Top-selling books identified.

## Files
- bookstore_analysis_project.sql
- bookstore_dataset_50_rows.csv
## SQL Queries Performed

1. Total Books Count
2. Total Revenue Calculation
3. Top Selling Books
4. Revenue by Category
5. Revenue by City
6. Average Book Price by Category
7. Highest Revenue Generating Book
